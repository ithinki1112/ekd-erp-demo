# EKDLABS ERP · 입금/미팅 관리 데모

계산서/입출금 매칭 화면에 추가할 기능을 검토하기 위한 프론트엔드 프로토타입입니다.
빌드 도구 없이 HTML 파일 하나로 동작하며, 데이터는 보는 사람의 브라우저(localStorage)에만 저장됩니다.

> 이 저장소에 포함된 업체명·담당자명·금액은 모두 **데모용 가상 데이터**입니다.

## 기능

**월간 요약 대시보드** — 첫 화면
- 이번 달 총 입금 예정액 / 입금 완료액 / 미입금액 / 수금 진행률
- 업체별 입금 현황, 담당자별 수금률, 월 캘린더, 다가오는 미팅

**입금 관리**
- 업체별 매월 입금일(1~31일·말일)과 요청 금액 등록
- 담당자, 결제 수단, 세금계산서 발행일, 메모
- 알림 시점(D-7 / D-3 / D-1 / 당일)과 채널(사내알림·이메일·카카오톡·SMS) 설정
- 목록에서 인라인 수정, 거래 상태(활성/중지), 입금 확인 처리

**미팅 일정**
- 미팅 일시·소요시간·진행 방식·장소, 참석자(우리 측 / 고객 측)
- 회의록(논의 내용·결정 사항), 액션 아이템(할 일·담당자·기한·완료 체크)
- 미팅 전날 알림 설정, 회의록 텍스트 복사

**알림 센터** — 입금 D-day와 지연 일차, 미팅 전날 알림을 자동 집계

## 사용법

캘린더의 일정이나 대시보드 목록 항목을 클릭하면 상세 내용을 보고 그 자리에서 수정할 수 있습니다.
데이터를 초기 상태로 되돌리려면 브라우저 콘솔에서 `localStorage.clear()` 실행 후 새로고침하세요.

## 로컬에서 열기

`index.html` 파일을 브라우저로 열면 그대로 실행됩니다. 서버가 필요 없습니다.
